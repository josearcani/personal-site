# Gists

Fragmentos cortos y reutilizables de código y configuración que resultan útiles en distintos proyectos. Piensa en esta sección como una referencia personal: el tipo de cosas que los desarrolladores suelen guardar como GitHub Gists:

- Fragmentos de código y funciones utilitarias
- Comandos de shell y one-liners
- Plantillas de configuración (Docker, CI/CD, linters)
- Consultas SQL y scripts de base de datos
- Ejemplos de requests a APIs
- Notas de configuración de entornos
- Datos de prueba para tests y demos
